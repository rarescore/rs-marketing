# Extreme Plumbing & Rooter — Cinematic 3D Website

A complete Vite + React + TypeScript marketing site rebuilt from the public content of rooter-plumber.com.

## Run locally

```bash
pnpm install
pnpm dev
```

Create a production build with `pnpm build`. The generated static website is written to `dist/`.

## Experience

- Split-panel cinematic entrance inspired by the Canby website's threshold animation
- Scroll-controlled 3D cutaway pipe with root blockage, flowing water, inspection probe and live status readout
- Lazy-loaded React Three Fiber scene with post-processing removed automatically on mobile and lower-power devices
- Nine service offerings, company history, process, customer reviews, Los Angeles coverage areas and contact details
- Estimate form that prepares a pre-addressed email for the customer to send
- Responsive navigation, keyboard-visible focus, semantic structure and reduced-motion support

## Design system

- **Night pipe:** `#071016` — primary atmosphere and trust foundation
- **Emergency orange:** `#FF552E` — actions, urgency and service energy
- **Diagnostic aqua:** `#62E5D1` — status, availability and technical precision
- **Workshop paper:** `#F1EFE8` — editorial service sections
- **Typography:** condensed industrial system display face with an Avenir/Helvetica body stack
- **Signature:** the website opens like a service access panel, then reveals a live cutaway drain diagnostic

## Content source

Business facts, contact details, services, company history, service areas and review excerpts were adapted from the existing Extreme Plumbing & Rooter website. Confirm all operational claims and contact details with the client before production launch.
