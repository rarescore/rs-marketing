RS MEDIA GUARANTEED WORKING VERSION

1. Unzip this folder.
2. Open index.html directly in Chrome/Safari OR run a local server:
   python3 -m http.server 8000
   then open http://localhost:8000
3. For GitHub Pages, upload the CONTENTS of this folder to the root of the repo.
4. Do not upload the zip file itself. GitHub Pages must see index.html at the root.

This version embeds CSS and JS directly inside every HTML page so asset paths cannot break.
