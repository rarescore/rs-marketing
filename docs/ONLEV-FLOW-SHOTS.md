# ONLEV Flow Shot Plan

These are production shots, not still-image camera effects. Each render uses **Frames** mode with an authored start and end frame so visible architecture, mechanisms, lighting, and material response must change over time.

Common settings: Veo 3.1 Lite, 16:9, one output, 8 seconds, 720p preview, no generated audio. Camera movement remains restrained because the primary motion comes from physical scene choreography.

## Acceptance rules

- Reject any result where the environment is static and only the camera moves.
- Reject warped apertures, rubbery metal, disappearing parts, invented objects, or geometry drift.
- Reject excessive bloom, neon, particles, fantasy light, or glossy science-fiction styling.
- Motion must read as ignition, calibration, and retraction in that order.
- The final frame must remain calm enough for live HTML copy and a scroll handoff.
