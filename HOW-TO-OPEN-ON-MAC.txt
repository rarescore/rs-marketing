ONLEV — HOW TO OPEN ON A MAC

This is a full Next.js website project. It is not a single HTML file, so double-clicking index.html is not how it runs.

EASIEST METHOD
1. Make sure you have an internet connection.
2. Double-click: OPEN-ONLEV.command
3. On the first launch it installs the required packages.
4. Your browser will open to: http://localhost:3000
5. Keep the Terminal window open while viewing the site.
6. To stop the site, click the Terminal window and press Control-C.

IF MACOS BLOCKS THE LAUNCHER
- Right-click OPEN-ONLEV.command and choose Open.
- Or open Terminal, drag OPEN-ONLEV.command into it, and press Return.

IF IT SAYS NODE.JS IS MISSING
Install Node.js 20.9 or newer from https://nodejs.org/, then double-click the launcher again.

MANUAL METHOD
Open Terminal in this folder and run:

  npx --yes pnpm@11.19.0 install
  npx --yes pnpm@11.19.0 dev -- -p 3000

Then open http://localhost:3000 in Chrome or Safari.

IMPORTANT
The first launch must download dependencies. After they are installed, later launches are much faster.
